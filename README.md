# Amazon Clone (React)

A fully functional Amazon-like e-commerce web application built using React. 
The project includes product listing, cart management, address handling, user authentication, 
and Razorpay payment gateway integration (test mode). It demonstrates real-world React concepts 
such as component-based architecture, state management, API integration, routing, and reusable services.

## Features
- User authentication (Login / Signup)
- Product listing & search
- Cart management (add, remove, quantity update)
- Address management
- Razorpay payment integration (test mode)
- Responsive UI

## Tech Stack
- React.js
- JavaScript
- Bootstrap
- Axios
- Razorpay API
